1. Навіщо в програмуванні окремий тип для «так» і «ні»?

Булевий тип потрібен, щоб явно виражати, що значення має лише два стани: істина або хибність.

2. Як сказати !(a && b) людською мовою?

Неправда, що a і b одночасно істинні

3. Чим && відрізняється від &?

&& - це логічне, а & - побітове

4. Чому програма не падає в if (x != null && x.name == "Іван"), хоча x порожній?

Тому що && використовує коротке замикання, типу якщо x == null, друга умова не перевіряється, і помилки не виникає

5. Як запхати 32 відповіді «так/ні» в одне число?

Використати 32 біти одного числа: "так" = 1, "ні" = 0. Так як кожен біт зберігає одну відповідь.

6. Що швидше: n % 2 чи n & 1?

n & 1 зазвичай швидше або так само швидко, так як перевіряє останній біт числа, щоб визначити парність.
